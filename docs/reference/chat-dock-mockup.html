Try it

Pick “3 questions” above. Step through with Next, type your own answer to any question, then check them on Review. Tap “Chat about this”, the context ring in the header, and the / button.

New in this revision

  • Model and context on the phone. The model sits under the run title and the context ring with its percentage sits beside it, in every state. Tapping it opens run details with token counts, branch and Pull base.
  • Several questions in one ask. One question shows at a time. Chips name each question and tick off as you go. Review lists every answer, and one button sends them together.
  • Your own answer to any question. The text box always belongs to the question on screen. On a pick-any question it adds to the ticked options.
  • Chat about this. The questions fold to one line and the composer turns into a normal reply that quotes the question. Nothing is dismissed until you send, and Back returns to the options.
  • The / button opens the command list.

Kept from the first pass

  • A status line with words above the composer, with one-tap Interrupt in thumb reach.
  • Questions dock above the composer, with the recommended option preselected.
  • Tool runs summarised by what happened.

Trade-offs

  • A three-question ask takes four taps when you accept every recommendation. The Review step is the price of sending all answers at once.
  • The docked panel covers about half a phone screen. The chevron folds it away to read the stream.
  • Sending a chat message sets the questions aside, as Claude Code does. The agent has to ask again afterwards.

What it touches

  • Composer, Dialogs and ChatHeader. The multi-question form already submits atomically, so the stepper is a front-end change.
  • Chat about this needs a dismiss-and-reply path in the answer endpoint.
  • Revisits ADR-0029 on where Interrupt lives, and ADR-0061 on where the context meter shows.
