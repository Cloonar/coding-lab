Direction A · round 2

Single scroll

The agreed direction with all nine ideas, editable schedules and the delete flow worked in.

New in this round

  • Schedules. Tap one to edit it on its own screen, a side panel on desktop. Run now, Delete and the next runs live there.
  • Delete. Stays in Danger zone. The dialog lists what is lost, and it explains a blocked delete before you try. See cloonar-nixos.
  • One save rule. Fields wait for the save bar, which names the changed sections. Sections tagged "applies immediately" act at once.
  • Errors at the field. Break the AFK branch pattern and press Save.
  • Inheritance. Every overridable field says inherited or set here, with a reset. Remote control now has its three states.
  • Only what applies. Pick the Host runner, the built-in tracker, or turn Autoland off.
  • New order. Agents and automation first, set-once sections last.
  • Readiness. Overview checks whether runs can start. See auth-service.
  • List. Fifteen repositories, what needs you on top, then recently opened.
  • Undo. Removing an import or discarding edits can be undone. Irreversible actions ask first.
  • Add. Adding a repository lands on its home with clone progress.
